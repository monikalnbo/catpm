# hashx 0.1.0

非加密哈希与校验和库（纯 CatBase 0.1.8，零依赖）。
全部算法对公开测试向量逐字节一致（64 断言，logs/hashx-build.log）。

## 函数清单（10 个公开函数）

| 函数 | 说明 |
|---|---|
| crc32(s) | CRC-32（IEEE 802.3 反射多项式 0xEDB88320，查表法） |
| adler32(s) | Adler-32 |
| djb2(s) | Bernstein djb2（h×33+c） |
| djb2_xor(s) | djb2 异或变体（h×33^c） |
| sdbm(s) | sdbm（h×65599+c） |
| fnv1a32(s) | FNV-1a 32 位 |
| fnv1_32(s) | FNV-1 32 位（先乘后异或，对照用） |
| xor32(a,b) | 32 位异或的算术模拟（公开为工具函数） |
| to_hex32(v) | 固定 8 位小写十六进制 |
| crc32_hex(s) / adler32_hex(s) | 直接输出十六进制串 |

## 测试向量（全部来自公开标准）
- crc32: ""→0、"abc"→891568578、"123456789"→3421780262、"Wikipedia"→2913648686、"The quick brown fox…"→1095738169
- adler32: ""→1、"abc"→38600999、"Wikipedia"→300286872
- djb2/sdbm/fnv 系: 空串、"abc"、"hello"、"123456789"、"Wikipedia"、fox 句子各 8 输入全套

## 用法
```
import ./deps/hashx/index.catc as hashx
# hashx.crc32("abc") -> 891568578
# hashx.fnv1a32("hello") -> 1335831723
# hashx.crc32_hex("abc") -> "352441c2"
```

## 实现说明与边界（如实记录）
- catbase v0.1.8 无位运算符：xor 用逐位算术模拟（xor32），乘法掩码用 `% 4294967296`，全部中间值保持在 i64 安全区。
- **64 位变体不做**：FNV-1a 64 的偏移基 0xcbf29ce484222325 本身超出 i64 最大值 2^63-1，且 h×prime 乘积溢出 i64；语言无 u64 类型、无 2^64 回绕乘法，算术模拟需要三字长大数，超出本库范围。
- **md5/sha1 不做**：旋转与异或的算术模拟已被探针证明可行，但 64 轮×16 步 / 80 轮的纯算术实现体量大、速度慢，且两者作为加密哈希均已破解——工程量与安全价值都不成立，记录在案不做。
- **sha256 分工**：catpm 自身用系统 sha256sum 做包完整性校验（PROTOCOL.md §3.2），加密级哈希继续由系统工具承担，本库专注非加密哈希。
