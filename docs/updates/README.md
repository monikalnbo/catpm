# 更新记录（docs/updates/）

这个目录放**每一次更新的独立说明**。约定从 2026-11-11 起生效。

## 规矩

1. 每次更新（改代码、加工具、调行为、修 bug、改文档结构）都要在本目录**单独新建一份文档**，
   文件名：`YYYY-MM-DD-简短主题.md`，日期用实际改动日期。
   同一天有多次不相关的更新，就在文件名后加后缀，例如 `2026-11-11-srcprobe-and-registry.md`。
2. 每份文档固定写三块，缺一不可：
   - **这次更新做了什么**：新增/改动的工具、命令、文件，怎么用；
   - **解决了什么问题**：之前哪里不方便或根本不行，现在怎么行了；
   - **修了什么 bug**：逐条列出，并标明来源（哪份日志、哪次实测）。
     本次确实没有修 bug 就明确写「本次无 bug 修复」，不硬凑。
3. 文档里的结论必须来自真实运行记录，不编造输出；原始日志放 `tools/` 或 `logs/` 对应位置，
   文档里引用日志文件名。
4. 更新文档**随本次更新一起提交、一起推送**，不留在本地。
5. 文档用中文大白话写，命令和输出保持原样。
